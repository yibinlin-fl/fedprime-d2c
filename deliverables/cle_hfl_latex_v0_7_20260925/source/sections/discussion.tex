\section{Discussion and Limitations}

\textbf{Shortcut suppression is not the same as task utility.} On the original Asymmetric-HFL setting, PEW+BER reduces pooled DSA by 65.52\%, but not every client-level utility metric improves. Under FedDF-fidelity, DSA falls from \(0.136989\) to \(0.029012\), while the frozen utility gate fails. On held-out map2, BER has the best pooled shortcut--utility trade-off across the four matched objectives, yet CVaR-DRO has lower DSA on c0 and c1. We therefore report DSA and task utility as separate outcomes.

\textbf{PEW is taxonomy-assisted.} It learns a fixed coarse corruption-family taxonomy from public synthetic corruptions, unlike taxonomy-free environment inference such as EIIL \citep{creager2021eiil}. BER has an exact effective-distribution interpretation for the resulting proxy groups, but the current PEW error makes the conditional bridge to the true environment trivial. The proxy non-identifiability result formalizes this gap. We therefore judge behavioral mitigation with paired DSA rather than proxy statistics alone. The deployable method is family-level; true operator information is used only for controlled construction, sealed DSA evaluation, and Oracle audits.

\textbf{The evidence is still narrow in training and data variation.} The held-out map2 objective comparison spans training seeds 0/1/2, while the local-first factorial, map1 replication, and FedDF-fidelity experiment use seed 0. All core experiments use one controlled CIFAR-10 private task and a fixed non-IID partition.
