# V0.7-writing 语言与“AI味”审计

日期：2026-10-14。

## 审计目标

本轮只改善论证节奏和句子自然度，不改变公式、实验数字、引用键、证据状态或科学边界。冻结版 V0.7 未被修改。

## 已处理模式

1. 删除 Abstract、Introduction 与 Conclusion 之间重复的口号式总结。
2. 将“we therefore / this finding motivates / taken together”式模板过渡改成由上一条证据自然推出下一步的问题链。
3. 收紧过度防御句：必要限制保留一次，不在每个章节重复声明。
4. 避免把 PEW 分类器、已有重加权思想或 counterfactual 一词单独包装成创新。
5. 拆分同时承担问题、方法、结果和限制的过长句，保留主语和科学动作。
6. 保持术语稳定：CLE-HFL、DSA、PEW、BER、local-first、taxonomy-assisted 不做同义词漂移。
7. 将已完成、条件性、待补证据和禁止表述分别交给论断台账，而不是靠模糊语气掩盖。

## 本轮没有做的事

- 没有为了“更像人写”而改动实验数值或统计单位；
- 没有删除 taxonomy、单数据集、固定 partition、非统一 utility 等真实限制；
- 没有把 pending 实验写成已完成结果；
- 没有覆盖原始 V0.7 源码。

## 投稿前仍需人工确认

作者应在目标会议页数确定后做最后一次逐段朗读，重点检查个人常用表达、段落长度和图表引用位置。该步骤属于作者声音校准，不应交给自动“humanizer”改写科学事实。
