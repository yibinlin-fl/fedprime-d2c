\begin{abstract}

Model-heterogeneous federated learning (HFL) allows clients with different architectures to collaborate. Existing corruption-robust pipelines, however, usually treat corruption as label-preserving nuisance variation. We study \textbf{class--corruption entanglement (CLE)}, a controlled failure mode in which client-specific associations between task classes and corruption operators turn corruption into a directional class cue. To distinguish this behavior from ordinary image degradation, we evaluate the same semantic source under multiple operators and introduce \textbf{Directional Shortcut Alignment (DSA)}, a probability-scale contrast aligned with the pre-registered training binding. We characterize the assumptions under which DSA identifies this paired operator response and prove that improvements in an unconstrained pseudo-environment proxy cannot, by themselves, certify reduced CLE dependence. A matched HFL-versus-Local factorial shows a predominantly local-first pattern in the evaluated seed-0 setting. The resulting intervention is communication-agnostic: a taxonomy-assisted coarse \textbf{Public Environment Witness (PEW)} supplies pseudo-environments, and \textbf{Balanced Environment Risk (BER)} compresses class-conditional support imbalance across them. Completed controlled studies show DSA reductions across binding maps and communication bases, while also exposing settings in which task utility does not improve. The method is therefore a targeted mitigation for controlled CLE, not a taxonomy-free or universally utility-preserving HFL plug-in.
