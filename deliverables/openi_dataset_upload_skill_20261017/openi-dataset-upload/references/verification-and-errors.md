# 上传验收、记录与排错

## 完整上传卡

```text
目的/数据版本：
操作范围：仅准备 / 用户手动 / 已授权执行CLI
本机文件绝对路径、bytes、SHA256、预期包内根目录：
目标数据集显示名、拥有者、准确repo_id、页面URL：
是否已创建/可复用、可见性、写权限、存储位置（如适用）：
上传方式：网页 / CLI
CLI路径/版本、whoami身份（不含Token）：
准确远端文件名和所需子目录：
网页照填步骤或精确命令：
验收方式、已有同名文件的处理：
记录文件位置（当前项目）：
```

显示名与repo_id可能不同；任务搜索显示名、上传用repo_id、入口找精确文件名，三者分别记录。

## 证据层级

1. 本地核验：输入文件的bytes/hash及包内结构正确；没有证明远端已存在。
2. 上传调用：记录命令目标、SDK版本、开始/完成状态、exit code，不包含Token。
3. 远端可用：刷新对应数据集文件列表，核对远端名称/路径、大小、处理状态与可见性。
4. 强完整性：平台提供可信hash时比较，或独立下载到新目录再重算并与源文件一致。

只有第1项不能写“远端SHA256已验证”；没有执行上传时不能写完成。若只确认远端可见而未重下，
如实写“文件可见/大小已核对，远端内容hash未独立验证”。必要时再核验任务可搜索/挂载，但不
启动训练。SDK内部是否做校验不能替代你实际观察到的验收证据。

独立下载先创建本地目标目录，不覆盖旧文件。按本机3.0.1的实际帮助：

```text
openi dataset download OWNER/DATASET --filename REMOTE_FILENAME --local_dir NEW_LOCAL_DIRECTORY
```

不要使用未核验的旧版下载参数顺序；大量下载要考虑时间和带宽，不为每次教程默认下载大包。

## 排错

| 现象 | 先核对 |
|---|---|
| 401/未登录 | whoami、目标账号和令牌状态；不输出凭据，不立即重传 |
| 403/无权写 | 数据集拥有者、组织角色、写权限与可见性；不只重做Token |
| 目标不存在/404 | 是否已网页创建、repo_id是否路径而非显示名 |
| 本地文件找不到 | 绝对路径、引号、文件名；不让CLI自己猜目录 |
| 进度100%但网页无文件 | 合并/处理、错误日志去敏、是否传到别的数据集或子目录 |
| 同名旧包存在 | 对比版本/大小/hash；明确处理，未经许可不删、不覆盖 |
| 上传不稳定 | 网络、代理、SDK版本及源文件是否变化；有界重试，不无限循环 |
| 日志初始化或DLL错误 | 先排SDK日志目录写权限/当前进程PATH，不能直接判Token失效 |
| 训练找不到包 | 任务挂载的是哪个数据集、远端精确文件名、包内结构；不是上传进度问题 |

完成后将repo_id、页面、远端名、本地hash、SDK和验收层级记入当前项目handoff/数据记录。
不把新课题状态写到FedPRIME或用户级Skill中，也不因完成上传自动启动实验。
