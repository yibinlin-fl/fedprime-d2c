# 先创建目标，再选网页或CLI上传

## 1. 上传前准备

明确当前项目的数据用途、版本、文件/压缩包绝对路径、bytes/SHA256和可见性。
压缩包中的根目录与训练入口期望一致；命名建议包含项目、协议、版本与日期，但这不是平台限制。
不把API Token、.env、.git、其他账号凭据或未授权数据放入输入包。

## 2. 在OpenI网页创建/确认数据集

1. 登录`https://openi.pcl.ac.cn`，确认当前账号及目标拥有者。若是组织，先确认组织写权限。
2. 打开平台的数据集管理入口，进入新建/创建数据集；若当前UI把它放在项目的数据集页，
   从实际项目页面进入。按钮名称/布局会变，不伪称本轮已看见用户账号页面。
3. 填数据集名称、用途/介绍及页面要求字段；按用户指定设置公开/私有、所属个人/组织和权限。
   如页面把数据集与项目/仓库关联，先确认关联对象；不要把新研究数据默认为公开。
4. 提交创建空数据集，或确认已有目标确实是本次版本。若页面强制同时选文件，按当前流程，
   不把“空数据集”当不可变平台要求。
5. 记录创建后的页面URL、显示名、拥有者和平台给出的CLI repo_id或对应上传示例。
   CLI使用owner/路径，不保证它等于中文显示名；不要凭标题或任意URL片段猜测。
6. 如果页面要求存储/算力集群，记录实际选项并确认未来任务能挂载。不能从旧SDK教程照抄
   cluster参数，本机3.0.1公开CLI没有该参数。

创建是外部操作。用户只要方案时先输出可照填字段；若需要用户操作，应给具体名称/字段，
操作后只需让用户提供数据集页面或repo_id，无需Token。

## 3. 网页手动上传

按用户2026-10-17确认的默认规则：单文件不超过500MB（含500MB）走网页手动上传；
超过500MB直接走CLI。先核对本机文件大小，再推荐路线，不把大文件继续交给网页尝试。

进入刚确认的数据集 → 文件/上传区域 → 选择或拖入已核验本地文件 → 确认目标与远端名称 →
开始上传 → 等待文件状态/处理完成 → 刷新文件列表核验文件名和大小。

浏览器文件选择器里使用本地路径；不把Windows路径当云端挂载目录。只有明确需要并核验过
包内结构时才解压再传，不能因为页面接受压缩包就假定训练容器会按预期自动解压。

小文件遇到页面拒绝、上传不稳定或用户另有指定时可使用CLI，复用同一数据集。
500MB分流来自用户确认，不声称本轮在线核验了官方硬上限；若实际页面限制更严格，按页面
调整。旧记录中的512MB不再用于本用户的默认路线，也不引用早年活动的20GB/2GB要求。

## 4. 交给用户照填的建集卡

```text
显示名：当前项目的准确名称
拥有者：用户/组织
可见性：按用户要求；未明确时标待定，不公开上传
用途/简介：数据内容、版本、训练/评价用途
关联项目或存储位置：按实际页面填写
预期上传文件：本机绝对路径、bytes、SHA256
创建后回传：数据集页面URL和准确owner/repo_id
```

不要求用户发送个人设置页面、Cookie、Token或包含凭据的截图。
