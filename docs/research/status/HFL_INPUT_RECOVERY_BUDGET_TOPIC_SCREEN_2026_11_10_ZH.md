# 新选题纸面筛查｜预算受限的客户端图像恢复

2026-11-10。上一条「其他客户端坏图集中导致持续负迁移」未通过短预算预检，作者确认收住。此处只记录一个相邻方向，状态为待查重与数据可行性检查。尚未定题、实现或启动实验。

## 问题与可观测条件

如果多个客户端的本地训练图像可以用有限代价重新获得更清晰的版本，有限的恢复额度应花在哪个客户端？例如边缘摄像头已缓存原始帧，但带宽或读取成本只允许本地提取一部分原图。每次恢复替换同一源图的一条本地训练记录，标签与样本量固定。低质量图像和已获得的替代版本留在本地。选择前只有当前图像、已知采集或编码记录、恢复成本等确实可见的信息。仅被选中的图像能获取配对高清版本，最终评价标签留作报告。开题前必须确认一个真实来源，合成配对只能作为快速可行性验证。

令 \(S\) 表示申请恢复的记录，\(b_s\) 为每条恢复的成本，目标是在 \(\sum_{s\in S} b_s\le B\) 下减小独立评价的联邦客户端平均损坏风险。先研究两项量：来源客户端 \(j\) 自己的损坏准确率变化，以及其他客户端 \(i\ne j\) 的平均准确率变化。后者衡量某一端的恢复操作是否能通过联邦协作惠及其他端。因为未修改其他客户端的输入，匹配的本地独立训练是相应的参照。目标是一个待验证的研究问题，分配算法仍待机制证据。

最弱假设是可以在有限额度内获得一部分记录的同源、同任务标签的更高质量版本。跨客户端收益还要求这些数据足以改变来源模型输出，且改变能够通过通信传到受方。仅有来源客户端的收益时，题目容易退化为局部清洗。若只有预先看到高清版本或评价答案才能挑出受益方案，也无法形成可执行方法。

## 近邻与可证伪设计

- ActiveClean 已经研究预算有限时主动选择待清洗记录，Sample-level Data Selection 已在联邦学习中研究预算约束下的高质量样本选择，TITANIA 已实证比较联邦表格数据清洗对效用和公平性的影响。若立题，关键增量是辨认**恢复同源输入质量对其他异构客户端的可复现影响**，并据此分配预算。不能单独把主动清洗、预算或联邦当作创新。 [ActiveClean](https://www.vldb.org/pvldb/vol9/p948-krishnan.pdf) · [联邦样本选择](https://ieeexplore.ieee.org/document/9488723/) · [TITANIA 作者代码](https://github.com/sara-bouchenak/TITANIA)
- 和 CLE 的区别在于直接改变被选中记录的输入质量。Public-JSD 约束预测一致性，PEW/BER 通过伪环境调整损失，CRSF/CVRS 使用公共响应信号。本题的价值只能通过实际恢复干预后的独立评价测量，未选中的高清版本或通用公共响应不可充当部署信息。
- 最小检验可复用同一已有模型状态和同源合成 CIFAR 输入。预先固定两个来源客户端，匹配预算、图像类别构成、更新数与公开批次，比较零恢复、同样数量恢复于来源 A、同样数量恢复于来源 B。只做 1–2 轮配对训练，分别测本端和他端在同一独立验证集上的变化，并检查在不通信的对照下受方无相应变化。若两个来源都只改善本端、他端变化不稳定或不具备实际量级，就不设计预算分配算法。该检验尚未运行，预计比重跑完整 RAHFL 轻，实际成本未知。
- 进一步公平比较可保留完整 RAHFL 作为零恢复参照，但要把恢复预算视为额外信息。若提出方法，至少对比同预算的随机分配、均分与优先恢复最差来源等规则，训练和评价信息匹配后再谈优势。
- 暂不保留宽泛的「部署阶段损坏随时间变化 + 联邦测试时适应」作为优先候选。FedCTTA 已在 CIFAR-10-C 等输入损坏序列上做联邦持续测试时适应，当前没有足够区分的新问题。 [FedCTTA 作者稿](https://mdakilraihaniftee.github.io/assets/pdf/FedCTTA.pdf)
