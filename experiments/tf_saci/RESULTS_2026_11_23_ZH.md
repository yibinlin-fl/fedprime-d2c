# TF-SACI Gate 0 结果

**决定：工程自检通过，SSA 有绑定相关信号并触发干净图语义警示。Gate 1 暂缓正式训练。**

## 数据与可复现性

- 主评价输入包固定为 map2，partition seed 0，`alpha=1.0`，`rho=0.5`。每个 gamma 的四端 fit 样本数依次是 8,501、8,500、8,496、8,498，共 33,995。两条件匹配源图、任务标签及 OOF 折。完备性检查覆盖准备包清单、fit/audit 索引、主任务训练输入字节、四个初始化文件和冻结的两条基线恢复包。基线模型未加载。
- 11 项单测通过。第一次真实运行启动时发现客户端 0 有一个类仅 3 张源图，初始实现错误地要求每类至少 5 张，因而在生成首个缓存前停止。现规则将这 3 张图分到不同验证折，并保证每个训练折仍有该类支持。该修正先于结果计算，本轮从未按真实 corruption 标签调整特征、正则或切分。
- 相同配置独立执行两次，16 份 OOF 缓存 SHA256 全部相同。切片 CSV 逐字节匹配，逐类统计和配对差也一致。第一次成功运行累积输入校验和描述符计算 11.52 秒，线性探针拟合 13.09 秒，均为 CPU 计时。运行总耗时另含进程启动和结果写入。未启动 GPU、HFL 训练或 sealed 评价。

## 纹理是否含绑定信号

百分数为每端对切片内有支持的类别宏平均，再等权平均四端。预测取未加先验、未截断的 OOF 探针分数。它衡量离线探针预测能力，和主模型任务准确率属于不同评价。

| 描述符 | Gamma | 全部 fit OOF (%) | 干净 fit OOF (%) | 损坏 fit OOF (%) |
| --- | ---: | ---: | ---: | ---: |
| phi_tex | 0.0 | 29.70 | 33.44 | 25.97 |
| phi_tex | 0.9 | 42.80 | 29.42 | 56.14 |
| phi_full | 0.0 | 31.84 | 35.31 | 28.36 |
| phi_full | 0.9 | 47.40 | 30.55 | 64.52 |

两条件的 16,966 张损坏 fit 图同源配对。`phi_tex` 的折外平衡准确率平均差为 **+30.17 pp**，逐客户端为 +24.01、+32.63、+32.31、+31.72 pp。`phi_full` 平均差为 +36.16 pp。观察支持固定绑定增强了低层统计的类别预测性。`phi_full` 保持预先指定的诊断角色。

## 干净图显示语义混入风险

17,029 张干净 fit 图在两个条件中同源。`phi_tex` 的干净图分数为 29.42%–33.44%，客户端的训练折众数基线为 10%（十类）或 14.29%（七类）。四个客户端在两个条件下全部超出预先指定的 +5 pp 警示线，超出幅度为 +14.46 到 +28.12 pp。干净图从 gamma0 到 gamma0.9 的探针差为 −4.02 pp，可由两条件训出的探针不同来解释。同类低层视觉特征在无绑定或无损坏时也有预测价值。下一阶段把整条偏置都加进 PoE 可能伤害语义分类，具体效用仍需独立验证。

288 个切片中有 176 个非空 operator 切片。算子切片中的真实标签分布与类支持可能随绑定变化，需结合每类样本数看。客户端 0 的最稀有类只有 3 个 fit 样本，宏平均对此类单个命中敏感。因此正文若引用，应保留跨客户端方向和支持数。当前没有对探针差做训练随机性推断。

PEW+BER 已在同底座降低 DSA 0.094490，同时 Clean 和 Mixed 分别下降 4.350 pp、约 1.79 pp。SSA 若要支撑收益，应在同底座、相同输入和预算下，达到接近或优于原 DSA 的水平，并保住更多 Clean 和 Mixed 效用。Gate 0 的 OOF 准确率无法用于填这张主模型表。

下一步先审计独立开发集的来源。CIFAR-10 的 50,000 个训练源 ID 中，冻结私有包用了 40,000 个互不重复的 ID，差集有 10,000 个候选。还需查是否用于初始化、公共资源或先前候选选择，再确定是否可用。可在独立开发集合上预注册任务效用评价及候选选择，正式 paired DSA 继续留封到方案冻结。考虑到干净图的警示，优先保留 CE-anchor 对照。若出现 clean utility 下降或 DSA 未达到目标，记录失败并停止叠加 CC-Mix、PS-PID。V0.11 的方法和结论仍以已有验证为准。
